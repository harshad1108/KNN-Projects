# 🏬 Mall Customer Loyalty Prediction

## 📌 Project Overview
This project focuses on predicting **customer loyalty** in a shopping mall using demographic and spending behavior data.  
The goal is to identify **high-value and loyal customers** using machine learning techniques.

---

## 🎯 Problem Statement
Given customer demographic information and spending patterns, predict whether a customer belongs to a **loyal / high-value customer segment**.

This helps businesses in:
- Customer retention strategies
- Loyalty program design
- Personalized marketing

---

## 📊 Dataset
**File:** `Mall_Customers.csv`

### Key Features:
- Gender  
- Age  
- Annual Income  
- Spending Score  

**Target Variable:**
- Customer Loyalty Category (Low / Medium / High)

---

## 🧠 Machine Learning Approach
- **Problem Type:** Classification  
- **Algorithm Used:** K-Nearest Neighbors (KNN)

---

## 🛠 Techniques Applied
- Data Cleaning & Preprocessing  
- Exploratory Data Analysis (EDA)  
- Feature Scaling  
- KNN Model Training  
- Model Evaluation  

---

## 🧰 Tools & Technologies
- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- Matplotlib  
- Seaborn  
- Jupyter Notebook  

---

## 📈 Results
The KNN model successfully identifies loyal customers based on spending behavior and income patterns, enabling data-driven customer segmentation.

---

## 📌 Conclusion
This project demonstrates how **KNN classification** can be applied to **customer loyalty prediction and retail analytics**, providing actionable insights for business growth.
