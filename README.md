# 🤝 KNN Projects

This repository contains multiple **real-world Machine Learning case studies** implemented using the **K-Nearest Neighbors (KNN)** algorithm.

---

## 📂 Projects Included
- Amazon Purchase Prediction  
- Mall Customer Loyalty Prediction  
- Resume Screening Similarity System  

---

## 🛠 Skills Demonstrated
- Distance-based Learning
- Similarity & Nearest Neighbor Search
- Feature Scaling & Normalization
- KNN Classification
- Model Evaluation

---

## 🧰 Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 🎯 Objective
To apply the **K-Nearest Neighbors (KNN)** algorithm on real-world datasets and build effective similarity-based and classification models.
