# 🛒 Amazon Purchase Prediction

## 📌 Project Overview
This project focuses on predicting whether a customer will **purchase a product on Amazon** based on user and product-related features.  
The goal is to model customer purchase behavior using machine learning.

---

## 🎯 Problem Statement
Given customer and product information, predict whether the customer will make a purchase.

This type of prediction helps in:
- Targeted marketing
- Sales forecasting
- Customer behavior analysis

---

## 📊 Dataset
**File:** `amazon.csv`

The dataset contains information related to:
- Customer attributes
- Product attributes
- Interaction features

**Target Variable:**
- Purchase decision (Purchased / Not Purchased)

---

## 🧠 Machine Learning Approach
- **Problem Type:** Binary Classification  
- **Algorithm Used:** K-Nearest Neighbors (KNN)

---

## 🛠 Techniques Applied
- Data Cleaning & Preprocessing  
- Exploratory Data Analysis (EDA)  
- Feature Scaling  
- KNN Model Training  
- Model Evaluation  

---

## 🧰 Tools & Technologies
- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- Matplotlib / Seaborn  
- Jupyter Notebook  

---

## 📈 Results
The model predicts customer purchase behavior with reasonable accuracy, demonstrating how distance-based learning can be applied to e-commerce analytics.

---

## 📌 Conclusion
This project shows how **KNN classification** can be used for **purchase prediction problems** in e-commerce platforms like Amazon.
