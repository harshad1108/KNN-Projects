# 📄 Resume Screening Similarity System

## 📌 Project Overview
This project focuses on building a **resume screening and similarity matching system** using **K-Nearest Neighbors (KNN)** and distance-based techniques.  
The goal is to identify resumes that are most relevant to a given job requirement or query resume.

---

## 🎯 Problem Statement
Given a collection of resumes, determine which resumes are **most similar** to each other based on skills, experience, and textual content.

This type of system is widely used in:
- Applicant Tracking Systems (ATS)
- HR analytics platforms
- Automated resume shortlisting

---

## 📊 Dataset
**File:** `Resume.csv`

The dataset contains resume information such as:
- Skills
- Experience
- Job roles
- Textual resume content

---

## 🧠 Machine Learning Approach
- **Problem Type:** Similarity / Recommendation System  
- **Algorithm Used:** K-Nearest Neighbors (KNN)

Text data is transformed into numerical vectors, and similarity is measured using distance-based methods.

---

## 🛠 Techniques Applied
- Text preprocessing
- Feature vectorization
- Similarity computation using KNN
- Resume ranking and matching

---

## 🧰 Tools & Technologies
- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- NLP techniques  
- Jupyter Notebook  

---

## 📈 Outcome
The system successfully identifies resumes that are most similar to a given resume or job profile, enabling efficient and automated resume screening.

---

## 📌 Conclusion
This project demonstrates how **KNN and similarity-based learning** can be applied to real-world **HR Tech problems**, improving recruitment efficiency and accuracy.
